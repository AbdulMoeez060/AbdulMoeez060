Full stack AI engineer. 5 years shipping web and mobile products, the last 2+ building LLM systems that run inside large companies.

### What I'm working on

- **Nexonomy**: a multi-agent platform where role-based agents (CEO, CTO, researcher, designer, QA, deployment) plan and build software together, with human approvals at every step. LangGraph agents served over FastAPI, a Node.js and TypeScript backend, and a Next.js frontend.
- **Enterprise rollout at a Fortune 500 company**: governed answers over company data, RAG and document ingestion, role-based access for agents, long-term memory, evals, and multi-model review.
- **Open-weight LLMs**: self-hosted models for workloads that can't leave the company network.

### Before that

- **Chip**: led the rebuild of native Swift and Kotlin apps into a single React Native app.
- **Krillpay**: payments with Cybrid, Plaid and Persona.
- **Free Hypnosis**: mobile app with 1M+ downloads.
