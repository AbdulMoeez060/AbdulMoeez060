<h3 align="left">🧭 How I build:</h3>

- **Agents that can be trusted with real data**: code computes the numbers, models explain them, and a critic model reviews every answer before a person sees it.
- **Humans stay in the loop**: approvals, audit logs and role-based access are part of the design from day one, not added later.
- **Evals before opinions**: golden sets and regression evals decide which model or prompt ships.
- **Full stack ownership**: from the LangGraph graph and the API to the React screen and the Kubernetes deploy.
